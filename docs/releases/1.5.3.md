# AI Sales Agent 1.5.3 发布说明

## 核心更新

### 1. 企业知识库升级为 PostgreSQL `pgvector` + 全文混合语义检索（Hybrid RAG）
- **数据库向量索引（Flyway `V21__knowledge_pgvector.sql`）**：
  - 启用 PostgreSQL `pgvector` 扩展，为 `knowledge_chunk` 新增 `embedding vector(1024)`、`embedding_model` 列与局部 HNSW 余弦距离索引。
  - 在原有组织隔离、`TEAM`/`PRIVATE` 权限边界与 `revision` 版本一致性之上，单条 SQL 完成向量相似度召回，杜绝跨库同步与越权召回风险。
- **默认适配 `qwen3.7-text-embedding-flash`（1024 维）**：
  - 复用组织在「设置 → AI 模型」中配置的千问 `Base URL` 与 `API Key`，单批 20 条并发向量化，精准统计 `KNOWLEDGE_EMBEDDING` Token 消耗。
  - 保留优雅降级：未配置模型或向量接口临时异常时自动回退全文检索，不阻塞文档上传与问答。
- **双路混合召回与 RRF 重排**：
  - 提问时并行走 `pgvector` Top 30 语义召回与 GIN 全文 Top 30 关键词召回，在 Python LangGraph 工作流中融合向量余弦相似度、词项重合度与双路 RRF 排名，显著提升同义表述、口语化与抽象问题的命中率。

### 2. 模型设置与存量知识库平滑迁移
- **设置 → AI 模型**：新增选填项「向量模型（Embedding）」，默认 `qwen3.7-text-embedding-flash`，可按需覆写。
- **企业知识库 → 资料库**：展示每份资料的「向量索引 / 仅全文」状态徽标与模型名称；为管理员新增 **「补齐向量索引」** 一键操作（`POST /api/v1/knowledge/documents/backfill-embeddings`），支持为存量老文档快速补齐向量。

## 升级注意事项
- 需确保 PostgreSQL 已安装并启用 `pgvector` 扩展（`CREATE EXTENSION IF NOT EXISTS vector;`）。
- Python 端零新增第三方依赖，部署完成后在宝塔面板重启 FastAPI（`ai-service`）项目即可生效。
