# AI Sales Agent 1.5.7 发布说明

## 核心更新

1. **自主 Agent 对话框左下角一键选模型与状态同步**：
   - 自主 Agent 对话框左下角升级为交互式模型选择器，可一键在已配置的独立 Agent 通道模型（如火山引擎方舟 Agent Plan：`doubao-seed-2.1-pro`、`doubao-seed-evolving`、`deepseek-v4-pro`、`glm-5.3`、`kimi-k3`）与默认主模型间自由切换，顶部与侧栏实时同步展示当前模型和通道状态。
   - 「设置 → AI 模型」支持维护 Agent 可选切换模型列表，并提供方舟 Agent Plan 常用模型一键填入。
   - 走独立 Agent Plan 通道调用时，不消耗也不受限于 MCP 免费对话配额。
2. **自主 Agent 独立用量面板**：
   - 自主 Agent 空间侧栏替换为独立的 `Agent 通道用量` 面板，单独展示 Agent 通道状态、当前模型、Agent 累计 Token（含输入/输出）、自主调用次数与按 Agent 模型 Top 消耗，与 MCP 助手额度面板彻底解耦。
3. **MCP 助手普通模型与向量模型独立配额**：
   - 新增团队向量模型总预算（`embedding_total_tokens`）与成员向量模型个人配额（`embedding_allocated_tokens`），MCP 助手侧栏同时展示普通模型与向量模型额度；「Token 分配」弹窗与管理员「团队管理 / 成员管理」页均支持按普通模型与向量模型独立分配和校验，防止大批量知识库文档向量化挤占日常对话额度。
4. **会话彻底隔离、MCP 7 天到期清除、Agent 本地/线上存储可选**：
   - MCP 助手（`LIGHT`）与自主 Agent（`AGENT`）会话按模式严格隔离，不再共享列表，并新增单条会话手动删除接口。
   - MCP 助手会话默认保留 7 天，到期后由后台定时任务自动物理清除（级联清理消息）。
   - 自主 Agent 空间支持在左侧会话栏一键切换 **「存本地」**（仅保存在当前设备本地、不写入服务器会话表，同时支持多轮上下文记忆）与 **「存线上」**（云端独立持久保存，不随 MCP 7 天清除）。
