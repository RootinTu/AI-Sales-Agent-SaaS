# AI Sales Agent 1.5.4 发布说明

## 核心更新

1. **助手结果输出默认渲染 Markdown**：
   - 业务侧「MCP 助手」与独立「自主 Agent」的结果输出全面采用 Markdown 排版，支持标题、加粗、列表、表格与代码块。
2. **极简清爽对话 UI**：
   - 移除助手消息外层重背景与内层结果卡片双层嵌套边框，参考资料改为紧凑横向胶囊标签。
3. **分场景动态思考链**：
   - 根据「知识库问答」「审批/任务/客户标准工作流」「自主 Agent 多步 ReAct 规划」输出对应的实时思考步骤链。
4. **严格隔离 MCP 助手与自主 Agent 能力边界**：
   - MCP 助手专注日常问答、知识库查询与标准工作流，禁止直接触发自主 Agent；多步自治任务统一由顶部「自主 Agent」空间承载。
5. **知识库语义召回降噪**：
   - 提升 `pgvector` 语义召回阈值并过滤明显弱相关噪声片段，减少无关文档引用。
6. **自动更新地址同步**：
   - 桌面端自动更新清单地址同步至迁移后的仓库路径 `RootinTu/AI-Sales-Agent-SaaS`。
