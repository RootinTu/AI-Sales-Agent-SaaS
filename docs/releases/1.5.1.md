# AI Sales Agent 1.5.1

## 界面结构：业务与自主 Agent 切割

- **自定义顶部栏一级切换**：全局顶部栏新增「全部业务」｜「自主 Agent」切换。默认进入「全部业务」，完整保留原有 CRM 左侧菜单与全部业务页面（含轻辅助「MCP 助手」与「Agent 运行」）。
- **自主 Agent 独立工作空间**（`/app/agent`）：切换后隐藏 CRM 侧栏，进入独立布局，包含新建 Agent 任务、自主对话与执行、运行历史与轨迹、工具与知识范围、多轮会话列表与 Token 用量；可一键切回上次停留的业务页面。
- **权限**：自主 Agent 空间仍仅对桌面客户端与企业 SVIP 组织开放；未授权用户点击时在顶栏下方提示，不打断当前业务；直接访问 `/app/agent` 显示锁定页。
- **MCP 助手**：业务区 MCP 助手固定为轻辅助模式（`LIGHT`），不再在页面内切换模式。

## 桌面客户端

- 窗口改为无边框（`decorations: false`），最小化 / 最大化（还原）/ 关闭按钮融合进应用顶部栏，顶部栏空白区域可拖拽移动窗口。
- 登录页、加载页与错误页提供桌面端标题拖拽条与窗口按钮。
- 新增窗口拖拽与控制所需的 Tauri capability 权限。

## 其他

- 顶部栏显示当前客户端版本号，便于确认更新是否生效。
- 修复助手聊天区顶栏固定 56px 导致窄屏或 125%~150% 系统缩放下内容被遮挡的问题。
- `deploy/server/nginx.conf` 为 `index.html` 增加 `expires -1`，避免网页端发布后浏览器读取旧版缓存（需在服务器 Nginx 配置中同步生效）。

## 兼容性

- 无数据库迁移，无后端接口变更。
