# AI Sales Agent 1.5.0

## 核心更新：双模式智能助手与自主 Agent

- **双模式切换（轻辅助模式 / 自主 Agent 模式）**：保留轻量快速响应的默认轻辅助模式，新增面向 **桌面端客户端** 与 **企业 SVIP 组织** 开放的自主 Agent 模式（`AGENT`）。
- **多轮短期记忆与 5 步 ReAct 自主规划**：自主 Agent 支持多轮对话历史上下文注入，以及 `Plan -> Execute -> Observe -> Re-plan` 多步工具调用循环与错误自修正。
- **CRM 与知识库深度联动**：扩展 17 项标准化 CRM / 知识库读写与智能跟进工具，支持知识库检索、客户详情/互动/商机/报价/邮件列表查询、线索跟进任务创建及 LLM 撰写个性化邮件审批单。
- **双端权限与安全校验**：后端 `/api/v1/mcp/capabilities` 与 `/api/v1/mcp/chat` 对桌面客户端标识（`X-Sales-Agent-Client: DESKTOP`）及组织套餐（`SVIP`）进行服务端校验，防止未授权越权调用；新增数据库迁移 `V20__agent_mode_support.sql`（向后兼容扩展 `model_call.purpose` 约束允许 `'AGENT_PLAN'`）。

## 包含未发布 1.4.1 优化项

- 企业知识库支持 Markdown 预览，完整显示标题、列表、表格和代码块，并支持源码切换。
- 知识问答结果支持 Markdown 渲染，兼容 UTF-8 与 GB18030 中文资料编码。
- 补齐客户邮件、手动与自动跟进、延期取消、收信配置等功能引导，并优化引导刷新与抽屉高亮体验。
