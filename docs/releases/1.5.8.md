# AI Sales Agent 1.5.8 发布说明

## 核心更新

1. **方舟 Agent Plan 模型三档官方分类与默认预设**：
   - 对照火山引擎方舟 Agent Plan 官方 AFP 抵扣规则与最新在售权益，将 13 个文本生成模型分为 **文本生成（极速 0.25x）**、**文本生成（标准 0.5x）**、**文本生成（进阶 2x~8x）** 三档（自动剔除即将下线的 `kimi-k3`，新增 `doubao-seed-2.0-mini`、`doubao-seed-2.1-lite`、`deepseek-v4-flash`、`glm-5.3-flash`、`deepseek-v4.1-flash-economy`、`deepseek-v4.1-flash`、`glm-5.4`、`kimi-k3.1-pro`、`kimi-k2.8-preview`）。
   - 设定默认推荐主模型为 **`doubao-seed-2.1-pro`**（进阶 2.5x），并在左下角选模型菜单按三档分组展示每个模型的 AFP 抵扣倍率。
2. **Agent 燃料值（AFP）三周期自动折算**：
   - 后端按官方公式 `AFP = (输入 token × 输入抵扣系数 + 输出 token × 输出抵扣系数) / 10,000` 自动折算各模型消耗，并统计 **近 5 小时（默认参考上限 2,000 AFP）**、**近一周（7,000 AFP）** 与 **近一月（20,000 AFP）** 三档周期进度。
   - 「设置 → AI 模型」按模型用量统计表同步新增 **估算 AFP** 列，并提供一键填入全部 13 个方舟分级模型预设按钮。
3. **自主 Agent 空间 UI 布局去拥挤优化**：
   - 将原本挤在左侧栏底部的厚重用量卡片移出，彻底释放左侧 **Agent 会话** 列表的展示空间，左侧栏底部仅保留轻量的「切回全部业务」按钮。
   - 对话区顶栏新增紧凑的 **模型与 AFP 胶囊按钮**（点击弹出轻量悬浮统计卡），并在左侧导航新增宽敞的 **「通道与用量」** 独立看板，清晰呈现 AFP 三周期进度条、按模型消耗明细与可一键切换的分级模型目录。
