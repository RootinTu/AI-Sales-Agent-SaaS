# AI Sales Agent 1.5.2

## 界面结构：自定义无边框顶部栏与自主 Agent 独立空间

- **自定义顶部栏一级切换**：全局顶部栏新增「全部业务」｜「自主 Agent」切换，默认进入「全部业务」，完整保留原有 CRM 左侧菜单与全部业务页面（含轻辅助「MCP 助手」与「Agent 运行」）。
- **精简侧边栏 Logo**：移除左侧边栏顶部冗余大 Logo，导航直接与自定义顶部栏顺滑衔接，释放垂直空间。
- **自主 Agent 独立工作空间**（`/app/agent`）：切换后隐藏 CRM 侧栏，进入独立布局，集成新建 Agent 任务、自主对话与执行、运行历史与轨迹、工具与知识范围、多轮会话列表与 Token 用量，支持一键切回上次停留的业务页面（桌面客户端 / 企业 SVIP 专享）。
- **桌面端无边框窗口**：Tauri 窗口升级为 `decorations: false`，将最小化 / 最大化（还原） / 关闭按钮与拖拽区域融合进自定义顶部栏，并在登录页、加载页与错误页同步提供标题控制条；顶栏展示当前客户端版本号。

## 管理员控制台功能升级

- **成员管理增强**：成员列表直接展示每位成员的 AI Token 分配额度与消耗；管理弹窗一站式集成角色/状态维护、Token 额度配置、**重置登录密码**（`PUT /api/v1/admin/members/{memberId}/password`）与**强制下线**（`POST /api/v1/admin/members/{memberId}/revoke-sessions`），变更安全项自动吊销旧会话。
- **团队管理增强**：新增「团队 AI Token 预算总控」卡片（总额/已分配/待分配可视化与在线调整），以及「治理状态与快捷入口」卡片（展示 AI 模型通道状态并直达成员、日志与系统配置）。
- **日志管理增强**：支持将当前筛选结果导出为带 UTF-8 BOM 的 CSV 文件（兼容 Excel 中文无乱码），新增「仅看失败」一键快捷筛选。

## 其他修复

- 修复助手聊天区顶栏固定 56px 导致窄屏或 125%~150% 系统缩放下内容被遮挡的问题。
- `deploy/server/nginx.conf` 为 `location /` 增加 `expires -1;`，避免网页端发布后浏览器继续命中旧版 `index.html` 缓存。
