# AI Sales Agent 1.5.6 发布说明

## 核心更新

1. **双通道模型分流（支持火山引擎方舟 Agent Plan）**：
   - 新增可独立开关的「自主 Agent 专用模型」配置（支持火山引擎方舟 Agent Plan `/api/plan/v3`、通义千问及任意 OpenAI 兼容接口），API Key 独立 AES-256-GCM 加密存储并支持独立连通测试。
   - **MCP 助手（轻量模式）**、**企业知识库（问答 + 向量检索）** 与聊天分析继续走默认主模型；**自主 Agent 模式**的多步自主规划与流式汇总自动路由至独立 Agent 通道（未开启时自动无缝回退至默认主模型）。
2. **按模型用量统计看板**：
   - 「设置 → AI 模型」新增按 `(提供商, 模型)` 拆分的用量统计表，直观展示各模型的成功调用次数、输入/输出与总 Token 消耗，方便对照各平台免费额度与套餐使用情况。
3. **企业知识库检索与引用五项增强（基于 Bank RAG Benchmark 实测）**：
   - **同文档邻近切片扩展**：为高分命中的前 3 份文档自动补查紧邻后置切片并提升 `top_k` 至 6，缓解规程类 PDF 首页抢槽导致参数页漏召回问题。
   - **已废止/草稿文档降权**：常规提问时自动对标记“已废止 / 征求意见稿 / 旧版 / 草稿”的候选施加降权（历史提问不降权），确保现行主规程优先召回。
   - **单文档槽位上限**：每份文档优先最多占 2 个槽位，提升多跳检索与相似文档场景下的跨文档完整召回率。
   - **0 引用拒答清空来源与检索分段耗时埋点**：模型明确拒答且无引用时清空无关参考来源并保留精准拒答说明；`model_call` 审计记录拆分写入 `embedMs / vectorDbMs / lexicalDbMs / adjacentDbMs`。
   - **Nginx 网关超时与上传大小对齐**：将 `/api/` 的 `proxy_read_timeout` 调整至 `180s`、`client_max_body_size` 调整至 `12m`。
