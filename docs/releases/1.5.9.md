# AI Sales Agent 1.5.9 发布说明

## 核心更新

1. **自主 Agent 左下角选模型升级为「左右分栏」布局**：
   - 左侧固定展示「文本生成（进阶） / 文本生成（标准） / 文本生成（极速） / 默认通道」分类栏，鼠标悬停或点击即可快速切换右侧模型列表。
   - 右侧模型行采用单行不折行布局，AFP 倍率、`默认` / `推荐` 徽章与勾选图标统一右对齐且强制不换行，彻底解决长模型名折行与徽章竖排挤压问题。
2. **补齐历史方舟消耗统计与「校准控制台 AFP」基线**：
   - Agent 用量统计 SQL 同步纳入所有历史 `VOLCENGINE_ARK` 成功调用记录，避免遗漏早期历史消耗。
   - 新增数据库迁移 `V24__agent_afp_calibration.sql` 与 `PUT /api/v1/ai/model/agent/afp-calibration` 接口：在「自主 Agent 空间 → 通道与用量」点击 **「校准控制台 AFP」**，填入方舟后台当前已用 AFP（含站外或历史消耗，如 `95`）即可立即对齐三周期进度条；后续本系统新增调用自动按 `校准基线 + 校准后新增 AFP` 累加，不重复计算，窗口滚动过期后自动回归实时统计。
