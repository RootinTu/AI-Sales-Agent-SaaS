# AI Sales Agent 1.6.0 发布说明

## 问题修复

1. **修复自主 Agent 模式选模型时弹窗高度反复跳动的问题**：
   - 为多分类左右分栏模型选择器固定弹窗高度（`clamp(240px, calc(100vh - 180px), 360px)`）并显式约束 Grid 轨道（`grid-template-rows: minmax(0, 1fr)`），避免因不同分类下模型数量差异导致向上锚定弹窗高度变化、引发左侧分类按钮上下位移与 `hover` 反复切换的死循环。
   - 为左侧分类栏补齐内部滚动与防挤压样式，右侧模型列表在打开或切换分类时自动回到顶部；仅单分类（默认通道）时保持紧凑高度展示。
